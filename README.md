# AI Job Application Assistant

An AI-powered job application assistant built with Python, CrewAI, OpenRouter, and Streamlit.

## Features
- Fetch job postings from USAJobs.
- Analyze job descriptions and identify key qualifications.
- Tailor resume summaries and generate cover letters.
- Create personalized recruiter outreach messages.
- Coordinate multiple AI agents using CrewAI.

## Tech Stack
- Python
- CrewAI
- OpenRouter
- Streamlit
- USAJobs API
